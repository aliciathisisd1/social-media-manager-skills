# Amazon Video Ideation

Use this skill for Amazon workflow step 4: creating hooks and scripts for selected products.

## What to do

For each selected product, create:

1. **3 hook options** — short, punchy opening lines (first 2–3 seconds of video).
2. **1 short script** — written for a 15–30 second vertical video.
3. **A simple shot list** — 3–6 shots max.

## Output format

For each product:

- **Product name**
- **Hook options (3)**
  1. ...
  2. ...
  3. ...
- **Script**
  - Opening line (hook)
  - Middle (show the product / problem it solves)
  - Close (call to action, e.g., "Link in bio for UAE and KSA")
- **Shot list**
  - Shot 1: ...
  - Shot 2: ...
  - ...

## Rules

- Keep scripts short and suited for Reels / TikTok / Shorts.
- Always mention that it's available in UAE and KSA.
- Use a casual, friendly tone.
- Do not repeat the same hook style across products.
