# Historical Product List

This file lists every product already used for Amazon content. Before sourcing new products, `amazon-product-sourcing` must check this list and reject anything too similar.

## Similarity test

A candidate product is "too similar" if ANY of these are true:
- It solves the same problem in the same way as something below.
- It looks visually similar on camera.
- The resulting video would look almost identical to a past one.

Category overlap alone is not enough to reject. Visual + functional overlap is.

## How to use this list

When sourcing:
1. For each candidate product, scan this list.
2. Apply the similarity test (same problem + same way OR same visual).
3. If matched → reject and find a different product.
4. If unmatched → the candidate passes historical check. Continue with other rules.
