# Amazon Finds Sourcing

Use this skill for Amazon workflow steps 1–3: sourcing products, adding UAE + KSA links, and shortlisting.

## What to do

1. **Find products**
   - Look for unique, quirky, or trending Amazon Finds.
   - Focus on items that make a strong visual hook in short-form video.

2. **Add both regional links**
   - Amazon UAE link (amazon.ae)
   - Amazon KSA link (amazon.sa)
   - If one region is missing, flag it.

3. **Shortlist for selection**
   - Pick the strongest options based on: visual appeal, usefulness, surprise factor, price.
   - Present a clean shortlist for the client to choose from.

## Output format

For each product:

- **Product name**
- **Why it's interesting** (1 sentence)
- **Amazon UAE link**
- **Amazon KSA link**
- **Price (AED / SAR if available)**

Keep the shortlist to 5–10 products unless asked otherwise.

## Rules

- Always include both UAE and KSA links.
- Never invent or guess a link. If the link is not confirmed, mark it as "TBC".
- Skip products that are generic, boring, or already widely used.
